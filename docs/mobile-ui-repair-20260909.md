## 七项反馈的处理

| 反馈 | 本轮改动 |
| --- | --- |
| 手机／平板的悬浮球、浮动面板和双面板拖动卡顿 | 悬浮移动继续只提交缓存的 transform，禁止原生鼠标拖动再次接管。修正拖动期间的 blur 禁用规则被材质选择器覆盖的问题。中控增加指针捕获和指针／触点身份检查。双面板改为拖动分隔线及比例预览，松手时一次更新真实布局，避免每帧重排全部条目。 |
| 主界面标题不是 50/50，平板按钮未右对齐 | 使用统一的标题几何规则覆盖旧移动布局与快照主页的固定 130／150／208px 宽度：左右两列均为 minmax(0,1fr)，名称及其容器占满左列；右列按 DOM 顺序从左到右自然换行，每行右对齐；单行模式保留横滑及位置记忆。 |
| 贴边方形入口和条幅展开条目 | 左右边缘吸附后，收起入口变成至少 44×44px 的方形箭头，紧贴屏幕边缘。贴边入口首次点击立即展开条幅；条幅空白处、预设／分支图标区域以及新增“条目”按钮调用原生 Vue 条目动作。选择框继续负责切换预设／分支。自由悬浮时的双击主界面、长按中控继续保留。 |
| 中控打开、取消退出慢 | 在未挂载的节点上填充控件、应用尺寸并注入缓存主题，再插入页面。关闭前释放搜索键盘状态，移除可见窗口后清理输入；取消仅回滚改变过的设置，未修改时不重算主界面。撤销悬浮尺寸时仅同步一次几何边界。 |
| 日夜过渡生硬 | 取消触屏设备跳过动画的分支。支持 View Transition 的环境对工坊可见表面进行约 240ms 交叉淡入淡出；旧环境使用有限表面的颜色过渡，系统“减少动态效果”设置仍优先。 |
| 中控按钮样式不统一 | 中控按钮统一使用顶部通知按钮的底色、边框、圆角、字重、阴影和选中态；触屏按钮保留至少 44px 高度及独立点击区域。 |
| 切换美化卡顿 | 相同主题重复点击直接返回。新开中控复用已提交的主题缓存，不重新读取酒馆和主面板的样式，不再重新触发主界面主题按钮扫描。材质切换也走表面级过渡；降级路径不为每个条目及其子节点创建动画。同批原生样式变更按观察目标去重。 |

双面板的交互变化是明确的：拖动期间显示跟随手指的分隔线及比例，松手后改变两块面板尺寸。取消手势恢复原值；扩大触摸目标后，按下位置不再造成比例初始跳动。手机面板和工具栏明确放在同一个网格列，防止新增比例手柄把自动放置的面板挤入隐式列。主面板卸载时会取消在途的比例预览。

## 冻结视觉和生命周期

Aqua／Violet 的 tokens、`PMM_FROZEN_VISUAL_BASELINE`、已批准的 Aqua 主界面例外以及原始视觉 fixture 均未修改。主题文件改动集中在运行时缓存、提交时序和动画范围；此次明确要求的中控按钮及方形入口样式在各自 UI 模块中实现。拖动结束后恢复原有静态材质。

新增条目入口随悬浮控制器销毁；原生条目动作桥随 Vue 根组件卸载；取消拖动和中控退出会清理指针处理与预览节点。没有新增轮询、全树观察器或并行的旧鼠标拖动路径。
