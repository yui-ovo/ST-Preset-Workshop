# 预设与世界书共用收藏库（2.98.35）

- 在工坊的世界书页面，展开条目后点击复制按钮左边的星星，保存完整的独立副本。
- 修改原条目不会改动收藏。展开已经收藏的原条目，点击「覆盖收藏副本」才会更新收藏内容；不需要先保存世界书。
- 收藏库的条目标记为「预设」或「世界书」，共用原有分类和导入、导出功能。
- 点击收藏条目的「使用收藏」，可添加到当前工坊预设末尾，或选择一本世界书。
- 世界书收藏放回世界书时保留原设置，分配新的条目编号；放入预设时使用名称、正文和开关，转为普通系统条目。
- 预设收藏放入世界书时使用名称、正文和开关，世界书专用设置采用默认值。
- 添加到当前编辑的预设或世界书时只修改草稿，请点击对应的保存按钮。添加到未在工坊编辑的世界书时直接保存新增条目。

世界书原始字段存于现有收藏条目的 `extra.pmmWorldbookFavorite` 命名空间，旧预设收藏格式不变。来源书名和 UID 只用于识别收藏星星与手动更新，不是内容同步链接。世界书改名或重建条目后，已有收藏副本仍保留在收藏库。

目标选择器只读取世界书名称，确认添加时读取所选世界书。世界书星星索引仅在打开页面及收藏写入后刷新；预设星星匹配复用本轮收藏数据，避免每个条目重复解析完整收藏库。没有新增轮询或 DOM 观察器。

验证：`npm run test:shared-favorites`；本地 ST/TT 接口模拟环境下的真实 Vue + WebKit/Chromium 浏览器流程见 `scripts/test-shared-favorites-browser.mjs`。浏览器测试需配置本地 Playwright 与依赖资源路径，和现有布局测试相同。
