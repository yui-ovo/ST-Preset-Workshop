## 动画根因与修改

1. `startSurfaceMotion()` 原先在粗指针或存在触控点时直接返回，安卓和平板没有整块背景动画。
2. 冻结样式中的触屏控件关闭过渡，而旧动画块又对全部后代设置 `transition:none`。原生剩余控件各自变色，形成局部先变、整体突然切换的观感。
3. 两层普通透明度交叉淡化会在中间改变合成透明度；原生背景从动画中的透明底恢复时，还可能再启动一次背景渐变。

修改原有动画路径：

- 手机、平板、桌面统一启用约 280ms 的背景交叉过渡，主面板、顶部、条幅、中控和悬浮把手使用同一节奏。
- 仅在切换期间，为现有标题、按钮、条目名称及中控控件统一颜色过渡。限定 background-color、color、文字填充色与 border-color；不插值尺寸、位置、模糊或阴影。不再全量禁止后代过渡。
- 保留两个背景伪元素，在隔离的组内用 `plus-lighter` 混合，避免中途透明度下陷。该组合用于交叉淡化的依据见 [W3C CSS 工作组说明](https://lists.w3.org/Archives/Public/public-css-archive/2023Mar/0624.html)。没有使用页面截图或复制整棵 DOM。
- 动画结束/手势打断时，只对参与动画的几个表面完成恢复背景产生的原生 background-color 过渡，避免再闪一次；不结束其 transform 或其他业务动画。
- 连续点击合并主题请求，只有一个有限清理计时器；拖动开始立即结束材质动画，拖动中的主题请求在手势结束后统一提交。尊重“减少动态效果”和后台页面状态。

Aqua/Violet token 和 `PMM_FROZEN_VISUAL_BASELINE` 逐字未改，哈希 fixture 未重写。动画之外的最终背景、透明度、边框、阴影、模糊、尺寸与间距均保持。正文仍沿用前版可读性修复，只在挂载/主题及背景完成事件校准文字。
