# 2.98.23 预设快照存储

预设快照自动保存在对应预设的 `extensions.pmm_switch_snapshots` 中。正常导出预设会携带这些快照；连接同一酒馆、同一账号的其他浏览器可重新读取。换到另一套酒馆仍需导入预设或独立快照备份。

- 包含默认／普通快照、条目与分组开关、角色／聊天绑定。快照内不保存正文。
- 世界书快照仍使用原存储方式，可继续通过「快照备份」一起导入导出。
- 活动快照、手动调整状态等运行信息保留在当前浏览器，不跨浏览器自动应用。
- 角色卡／聊天标识不同的绑定需要重新设置。

## 保存与迁移

首次加载会读取酒馆已保存的预设。没有嵌入快照的预设会迁入原有本地记录；已经嵌入的预设以其中的数据为准，避免旧浏览器重新带回已删除的快照。迁移前的本地副本单独保留，可在「快照备份 → 迁移前的本地备份」中导出并按需恢复。

新增、覆盖、改名、删除或修改快照绑定后，先保存本地，再合并短时间内的操作写回预设。只有读回校验通过，窗口顶部才显示「已保存到预设」。失败时保留本地数据、未完成的保存记录，并提供重试；重新加载也会恢复未完成的保存。

当前酒馆接口保存的是完整预设文件。保存快照时先读取已保存的文件，只替换本扩展的快照字段，再原样写回；不会使用当前未保存的正文、参数和临时开关，也不会调用保存全局设置。确认成功后只更新宿主内存中的同一扩展字段，让后续正常保存／导出保留快照。

## 兼容与性能

普通 ST 与 TT 共用 `/api/settings/get`、`/api/presets/save` 接口，使用酒馆提供的请求头。ST 接口核对来源：

- [SillyTavern settings endpoint](https://github.com/SillyTavern/SillyTavern/blob/release/src/endpoints/settings.js)
- [SillyTavern preset endpoint](https://github.com/SillyTavern/SillyTavern/blob/release/src/endpoints/presets.js)

TT 对照本地 `tt-menu-reference` 的 `src/tauri/main/routes/settings-routes.js`、`src/scripts/preset-manager.js` 和 `settings_dto.rs`。已做兼容接口模拟测试，尚未在 TT 真机上实测。

没有定时轮询；聊天和临时切开关不写入快照文件。同一预设的原生重绘事件不触发额外读取。启动、打开快照窗口、真正切换预设和保存快照时会读取已保存的数据。一次批量迁移／保存共用一次预读和一次校验，连续修改合并保存。由于现有接口会返回全部预设，并写入目标预设全文，大量／很大的预设在迁移和保存时仍有额外 I/O 成本。

按上次确认的内容进行三方合并。同一快照在两处修改时保留原远端记录，将本地修改另存为无绑定的冲突副本；旧删除不会删除另一处刚修改过的记录。ST／TT 当前接口没有条件写入或事务，因此这不等于对完全同时发生的跨浏览器写入提供原子同步保证。

覆盖迁移、新浏览器读取、字段隔离、失败与丢失响应重试、删除、冲突副本、绑定转移、预设改名、重复导入的 ID、连续修改合并、关闭后的清理。浏览器用真实快照 UI 和隔离数据接口测试新建／覆盖／重试／备份及 390、820、1280 宽度；旧快照编辑器、改名恢复和备份弹窗测试继续保留。
