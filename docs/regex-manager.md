# 正则整理（2.98.40）

从工坊的「正则」入口打开。手机上下两栏，宽屏左右两栏。每栏可以独立选择预设正则、全局正则、当前角色或正则收藏；群聊及未打开角色时不能选择当前角色。

- 勾选任意多条，或全选搜索结果。拖动条目左侧的 `⋮⋮`，按插入线放到指定位置。选中的条目保持来源顺序。
- 跨栏拖动默认复制；两栏为同一来源时，拖动调整该来源的顺序。列表为空也能放入，靠近边缘时自动滚动。
- 点击名称展开详情。收藏在复制左边；复制、移动和删除作用于当前勾选的一批（点击未勾选条目的操作则只操作该条）。按钮复制／移动放到另一栏末尾；要选择插入点可使用拖动。
- 收藏保存完整、独立的正则副本，跟随酒馆账号设置保存，不执行，不与原条目自动同步，也不混入预设／世界书收藏。
- 保留作用范围、深度、修剪、宏替换、开关及未知字段；复制生成新的 ID。同名正则不会覆盖原有条目。
- 最近十步可撤销，关闭窗口后清除撤销历史。外部修改过列表时停止撤销，避免覆盖新修改。移动先保存目标，再删除来源；如果后一步失败，保留已保存的副本并提示检查。

不改变原生角色／预设的正则授权开关。首次使用未授权的正则来源，仍需在酒馆原生正则设置中启用相应来源。

## 实现和验证

`regex-manager.js` 在首次打开时按需加载；两栏只读取选中来源。预设选择器只搜索名称。正文仅展开时创建；长列表初始显示 80 条，滚动按需继续显示。拖拽只更新插入线与提示，批量操作每个目标写入一次，没有新增后台轮询或页面全量扫描。

复用主页面上下文与模块缓存。预设使用 `writePresetExtensionField`；全局与收藏调用原生 `saveSettings`。角色使用原生 `merge-attributes` 请求并检查 HTTP 结果后更新对应角色缓存，避免原生辅助函数吞掉请求失败。不会触发逐条聊天重渲染；退出时按需刷新原生正则列表。

`npm run test:regex-manager` 验证原始字段、批量顺序、目标失败、部分成功、外部编辑冲突与角色身份校验。

`npm run test:regex-manager-browser` 使用隔离的真实工坊页面，环境变量与 `test:shared-favorites-browser` 相同。覆盖 WebKit/ST 和 Chromium/TT 接口夹具、多选鼠标拖拽、触屏指针空列表放入、收藏、保存失败、千条列表初始 DOM 限制。浏览器夹具不等同于实体 iPhone 或完整 ST/TT 服务端实测。
