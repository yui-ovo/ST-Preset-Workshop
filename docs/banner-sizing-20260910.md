# 条幅尺寸与吸附入口修复

继续基于 `xiaoci-upstream-20260909`，接续 `064fba4` 的点击和主题性能修复。本轮按新的需求区分默认值与可调范围，替代旧记录中的“条幅最多半屏”限制。

## 本轮改动

- 吸附入口保留默认 28×28px，改为内侧 12px 圆角、贴边侧 3px 圆角的紧凑标签；箭头改为朝屏幕内侧的细线图形，缩轻阴影，继续使用当前主题的颜色和高光。拖动时不绘制新增阴影。
- 条幅默认宽高仍为当前视口的一半；手动上限改为当前视口完整宽高，下限独立计算，继续允许缩到默认值以下。同步修正滑杆范围、CSS 限制和几何边界，中控自身的 CSS 宽高限制也与其全屏数值上限一致。
- 条幅宽度小于设备默认宽度时，内部标题、文字、图标、按钮、间距按同一个比例缩小；扩大到默认宽度以上时保持用户设置的字号。没有改写用户保存的字号或按钮数值，恢复默认宽度后恢复原来的显示比例。
- 满屏条幅自动收回视口内。手柄靠近屏幕边缘，标题为它预留横向空间及足够高度；拖动使用缓存边界，避免将整个条幅拖到屏幕外。

以 390×844px 的视口为例：

| 项目 | 默认值 | 手动范围 |
| --- | --- | --- |
| 条幅宽度 | 195px | 117～390px |
| 条幅高度 | 422px | 253～844px |

宽度从 195px 缩到 117px 时，内部显示比例为 60%；例如用户设置的 15px 字号显示为约 9px，恢复宽度后仍按原设置显示。高度控制可见列表空间，条目仍通过原滚动容器阅读及按需加载。

## 实现与保护范围

缩放只施加于 `.panel-header` 和 `.quick-edit-dropdown`，外层 `.panel-wrapper` 不缩放，因此手柄、拖动预览和指针坐标继续使用屏幕单位。采用 CSS 的内部布局缩放，文字及固定尺寸控件共同变化；滚动判断继续比较同一容器的滚动尺寸。相关缩放与几何接口行为参照 [CSS Viewport 缩放模型](https://drafts.csswg.org/css-viewport/#zoom-property)。

宽度输入通过悬浮控制器的 `setBannerWidth` 缓存尺寸并只更新条幅节点；晚挂载或替换的原生条幅继承缓存。没有为缩放新增文档级 CSS 变量写入、Observer、轮询或逐帧字体扫描。移动过程仍只更新缓存的 transform，主题动画仍在拖动开始时退出。

`dist/workshop-theme-system.js` 和冻结 fixture 未修改。Aqua／Violet 既有材质、主题切换、中控底部按钮、预设草稿、酒馆选择权、快照事务和条目生命周期继续保留。

1. 左右吸附入口在日夜及各主题下的外观，首次点击展开是否正常。
2. 手机、平板横竖屏下，默认仍为半屏，手动能调到接近满屏及完整屏幕宽高；保存、取消和重开符合设置。
3. 从默认宽度缩小再恢复，检查名称、图标、按钮和间距共同缩放；选择预设、点击条目、输入与列表底部滚动仍正常。
4. 主界面、中控、条幅同时打开时，拖动缩小和放大的条幅、中控及双面板比例，检查边界、点击位置及跟手表现。
