# 中控美化与悬浮入口后续修复

> 条幅规则已作废：本文中的半屏默认/半屏上限、名称省略号及顶部“条目”按钮仅为历史记录，不再用于实现或验收。现行规则见[条幅名称与宽度规则](banner-contract-20260912.md)。

> 后续尺寸与吸附外观调整见[条幅尺寸与吸附入口修复](banner-sizing-20260910.md)：默认半屏保留，手动上限改为全屏，新增内部比例缩放。

继续在 当时的二改整合分支 上修复；作者基线仍为 `257f386`（2.97.29），此前的语义融合及移动适配保持。本文记录 `fd8a6cb` 之后的修复，并替代[上一轮记录](mobile-ui-repair-20260909.md)中关于 44px 吸附入口、View Transition 和中控按钮统一方式的说明。完整 upstream 取舍见[融合记录](upstream-integration-20260909.md)。

## 六项反馈

| 反馈 | 修复与行为 |
| --- | --- |
| 中控点美化要卡一会 | 移除 `document.startViewTransition` 路径。主题在合并同批请求的微任务中提交，不再等待浏览器截图或动画完成。重复点击同一主题仍直接返回，新开中控继续复用主题缓存。 |
| 吸附按钮再小一点 | 默认由 44×44px 改为 28×28px，箭头由 22px 改为 18px；沿用已设置的手柄宽度，左右贴边和立即展开逻辑保持。 |
| 魔法棒可用，但悬浮球无反应 | 补回上一轮误删的 `cancelPendingTap`。遗漏会让普通点击、长按、开始拖动和销毁报 `ReferenceError`。此前片段测试替代了这个内部函数，未能捕获缺失；本轮增加完整模块执行测试。 |
| 日夜过渡生硬 | 改为约 360ms 的背景层淡入淡出，支持渐变背景。只对少量窗口表面添加临时伪元素，不复制条目、不捕获整页、不用逐帧 JavaScript 改文字颜色；结束恢复原有材质，减少动态效果设置仍生效。 |
| 动画不能影响三类拖动 | 悬浮球／条幅、中控、双面板比例手势均接入主题交互状态。拖动开始停止当前过渡；期间的新主题请求合并保留，最后一个手势结束或取消后提交。继续使用缓存 transform 和比例预览，松手才写最终布局。 |
| 底部按钮样式改反了 | 删除所有中控按钮一律重绘的覆盖，底部操作按钮改为复用原先“顶部通知：开”的强调色底色、边框、文字色、胶囊轮廓及阴影，保留其夜间变体。通知关闭时继续显示原来的关闭态。主题选择及其他控件使用原有视觉规则。 |

自由悬浮球继续保留约 300ms 的单／双击判定窗口；贴边箭头首次点击立即展开。条幅空白处、预设／分支图标及“条目”按钮仍调用作者的条目动作。旋转屏幕的延迟任务增加了销毁清理，防止旧实例在重载后再次写状态。

## 视觉、状态及性能边界

Aqua／Violet tokens、`PMM_FROZEN_VISUAL_BASELINE`、批准的 Aqua 主界面修正规则及冻结 fixture 均未改动。新增视觉规则仅覆盖用户明确要求的底部按钮、吸附入口及临时主题过渡。主题过渡不更改窗口尺寸，不拦截点击，拖动期间移除动画层。

没有新增轮询、全树 Observer 或第二套 pointer handler。草稿、酒馆当前预设选择、快照事务、搜索、锁定提交、50/50 标题布局、半屏条幅及打开顺序沿用已有实现。
