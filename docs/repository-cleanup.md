# 2.98.59 仓库清理

`dist` 原有 50 份完整工坊包。本次删除 49 份不参与当前运行的历史包，只保留 `workshop-v3.02.js` 和当前功能模块。历史版本可从 Git 历史恢复，未改写仓库历史。`legacy` 中保留一份原始迁移 JSON，校验直接读取它，不再额外保存同内容的可执行 JS。

这项清理减少工作目录和更新安装后的文件占用，不代表旧文件曾被一起执行，也不会直接缩小已经下载的 `.git` 历史。
