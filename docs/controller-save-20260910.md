# 中控居中、重置与保存修复

接续 `fe72e59`。按本轮要求，中控每次首次打开或关闭后重开都先居中，随后可以拖动；已有的旧位置记录不再用于决定新打开的位置。已经打开的面板再次被唤起时仍只提升层级，不打断当前操作。

## 行为修复

- “恢复全部默认”立即同步当前设备的设置到条幅、中控和主界面。修复只有悬浮球／中控、主界面尚未挂载时缺少变量应用的问题，同时更新顶栏单行／多行选项显示。
- 重置前丢弃旧数字输入草稿和待绘制的滑杆值，避免恢复默认后又被迟到的预览覆盖。没有销毁控件监听器，重置后仍能继续调节。
- “保存更改”先提交未完成的数字输入和滑杆预览，再立即写入设置。保存成功后保持中控打开、维持当前位置、锁定状态和滚动位置，不重新构建面板。
- 显示约 1.8 秒的“保存成功”轻提示，沿用现有主题颜色，不遮挡触摸，也不依赖顶部通知开关。存储失败会显示失败提示并保留当前修改；不会错误提示成功。
- 保存成功后更新本次会话的取消基准。之后再改动并点击关闭，只撤销最近一次成功保存之后的修改，保存内容继续保留。
- 关闭和运行时销毁时回收提示计时器及数字输入结束后的边界检查计时器。

## 跟手与保护范围

悬浮球、中控和双面板比例手势超过原有启动阈值后，立即绘制第一处位移；后续高频采样继续合并为每显示帧一次，松手使用最终坐标。分隔线在挂载前设置第一处位置，避免先出现在容器起点。

双面板松手只更新比例调节项，取消预览不再重写主界面的布局变量。移动阶段继续使用缓存几何和外层 transform，双面板只预览轻量分隔线，没有增加列表重排、逐帧测量、存储写入或监听器扫描。

条幅宽高与字号隔离、单行名称、吸附、按钮排序、搜索、草稿及聊天更新刷新保护保持原行为。`dist/workshop-theme-system.js`、冻结 fixture 和 `dist/index.js` 均未修改；Aqua／Violet 材质未重新设计。
