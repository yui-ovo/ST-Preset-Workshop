## 剩余开销与本次修改

**日夜与皮肤切换：** 两层背景过渡使用的临时 CSS 变量原先按默认规则向下继承。变量只供面板的两个伪元素使用，却会随面板变化传给整棵条目树，增加过渡启动和清理时的样式计算。

在原有动画块中将两个私有变量声明为不向后代继承，伪元素明确继承所属表面的值。动画仍使用原来的背景、280ms 时长和混合方式。支持该 CSS 属性声明的浏览器可避免无关条目的变量传播；不支持的浏览器沿用原有继承行为，过渡仍能正常显示。没有增加 JS 功能探测、持续测量或新的监听器。

**双面板比例拖拽：** 原有毛玻璃拖拽简化绘制规则依赖未被手势逻辑启用的状态，面板还保留原生 `transition:all`。本次在触控开始时缓存两个面板引用，仅在实际拖动时临时关闭它们的过渡，并启用已有毛玻璃拖拽的简化绘制。

状态直接加到两个面板，使用只匹配表面的 class，避免整棵列表因祖先状态变化而重算样式。正常结束、取消、失去捕获和卸载清理沿用同一收尾流程，恢复原材质。每帧仍只更新网格轨道；比例、根变量与保存状态继续按原有释放流程同步。鼠标拖拽保留原路径，未改变比例范围、拖动方向、触发区域或双击恢复默认行为。
