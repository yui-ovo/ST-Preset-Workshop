# 对比操作、运行模式与关闭保护（2.98.52）

## 仅保留预设快照

在酒馆「扩展设置」展开原生样式的「预设工坊」折叠项，勾选「完整模式」运行完整工坊，取消勾选进入快照模式。无需再弹出模式选择器。切换记住选择，只重启工坊，不刷新酒馆。工坊存在未保存草稿时先走关闭保护；保存失败或选择继续编辑都不会切换，勾选状态恢复。正在编辑快照时，需要先完成或取消编辑。

仅快照模式保留原生预设栏相机、快照创建/覆盖/恢复、预设默认、角色和聊天绑定、预设内快照存储，以及柏宝箱原生分组开关。不会启动工坊主程序、浮动栏、批量管理、收藏、正则或世界书功能，已有数据不删除。随时可在扩展设置切回完整工坊。

`snapshot-only.js` 由 `node scripts/build-snapshot-only.mjs` 从现有快照和分组服务生成，复用同一份实现。修改原快照代码后必须重新生成；检查会阻止发布过期副本。快照入口不加载 Vue、主工坊或其他功能模块。

`runtime-resources.js` 为每个 iframe 记录资源归属；调用点通过 `pmmRuntimeResource(target)` 注册监听、观察器、计时器和界面元素，不修改宿主的原型、jQuery 或计时函数。停用先执行已有模块清理，再移除该运行实例剩余资源与接口。节点和监听目标使用弱引用，避免长期保留已关闭的面板。新增资源调用也须加入这一生命周期；启动代数保护用于取消切换前尚未完成的启动任务。

## 对比页替换正文与插入

两侧选择预设，点「比对」→「查看详细比对结果」，操作直接整合在差异列表里，没有另一个替换/插入窗口。

- 标题右侧优先显示版本号，如「v1.25 → v1.26」；无法识别时保留名称简称。短按反转方向。长按约半秒打开完整名称窗口，按当前方向分别标记为旧预设和新预设（由用户确认方向，不自动识别新旧），松手不会反转或清空选择；滑动取消长按。桌面也可右键或按 Shift+F10 查看。
- 列表标题右侧保留「替换 → 插入 → 关闭」循环按钮。默认隐藏勾选框，点其左侧「多选」后显示条目勾选框、全选文字按钮和底部批量操作；取消多选清空选择。关闭模式恢复原始对比列表和配对字母，隐藏搜索、选择和操作说明。
- 替换模式只显示可替换正文的条目，插入模式只显示待插入条目（包含需要先确定位置的条目）；其他条目在普通对比模式查看。
- 复选框外观沿用酒馆主题，固定列只负责对齐。列表按弹窗剩余高度滚动，不再限制为屏幕的 55%；「已选 N 条」放在底栏左侧，批量操作按钮放在右侧。
- 单条复选框放在名称前，仅插入模式保留单条按钮，位于百分比左侧；下方说明仍与名称左对齐。列表无外框和分隔线，上方操作按钮无边框且更紧凑，搜索边框使用方向按钮背景色，底部三个按钮统一高度。
- 单条替换位于正文对比窗口：A 标题编辑按钮左侧的「A→B」把当前 A 正文复制到 B 编辑框，B 侧的「B→A」反向复制。只修改本窗口正文草稿，点击「保存修改」走已有写回流程。
- 搜索框位于列表标题下方，全选只勾选当前搜索结果中可操作的条目，取消全选清空已选项。切换模式或方向会清空选择。百分比预留 `100%` 列宽，复选框独立固定列，说明与名称左对齐。
- 选择条目只更新勾选状态，不重建列表或重新匹配；操作仍通过目标面板原有撤销与保存流程。
- 「替换正文」只更新目标 `content`，保留名称、开关、角色、位置、顺序、分组和其他字段。对比识别出的正文相似配对会单独标注，需用户选择后应用。
- 「插入独有条目」复制完整条目，优先根据可靠对应的前后条目定位，批量条目保持来源顺序。按唯一 ID、其次唯一同名建立定位锚点，不用模糊正文匹配猜位置。
- 相邻顺序冲突、无对应邻居或分组归属不确定时，显示目标分组和插入位置选择；未选择不能执行。重名/重复标识无法确定对应的条目跳过，不自动生成重复项。
- 每批应用只记录一次撤销，条目与分组一并恢复。应用后仍需保存目标预设；打开弹窗后两侧内容或分组改变，则阻止使用过期结果。

`npm run test:compare-actions` 覆盖正文字段隔离、插入顺序、分组归属、歧义、运行模式生成及切换保护。
`npm run test:compare-actions-browser` 使用实际 Vue bundle 验证手机克隆对比页、桌面入口、反转、多选、自动/手动定位、分组撤销与模式切换未保存保护。
`npm run test:snapshot-only-browser` 直接加载独立快照模块，验证相机入口、无主工坊运行时、保存/覆盖/恢复、跨浏览器存储、角色聊天绑定、原生分组、失败重试及清理。
`npm run test:runtime-modes-browser` 通过真实扩展入口连续切换三轮，验证懒加载模块清理、快照数据保留、绑定监听不累积、原生折叠设置，以及不影响其他插件监听。

模式下实际手机的流畅程度仍需实机测试；这里不承诺消除美化或其他插件造成的卡顿。

## 沿用旧版开关

在缝合模式中，两侧选择要处理的预设，点任一侧铅笔旁的双箭头「沿用开关」图标。手机和桌面使用同一入口；原来的「比对」→「详情」入口也保留。

- 确认页显示完整名称，并标记「旧预设 · 提供开关」和「新预设 · 接收开关」。默认主面板作为旧预设、缝合面板作为新预设，只是初始方向，不会自动识别版本。
- 点「反转新旧」同时交换两份预设的标记和复制方向；最后点「新预设沿用旧预设开关」才会执行。打开、反转或取消都不会改动预设。
- 先按唯一条目 ID 对应，再按两侧唯一的同名条目对应。无法确定对应关系的重名、改名或新增条目保持新版状态；正文相同也不会自动配对。已移除手动对应区域。
- 显示已对应、将调整和保持新版的条目数。未对应条目维持新版现有开关。
- 只修改 `enabled`；正文、名称、角色、位置、顺序和其他字段保留新版数据。
- 应用后仍是草稿，需要保存目标预设。目标侧原有撤销按钮可一次撤销整次沿用。
- 预览期间任一侧数据改变会要求重新打开确认窗口，避免应用过期结果。
- 确认窗口在手机当前可见区域内居中，留出顶部和底部安全区；名称过长时在窗口内部滚动，标题和操作按钮保持可见。未保存关闭提示也采用相同布局。

## 关闭保护

关闭工坊时检查主预设、缝合预设、分支和世界书草稿，列出未保存内容，并提供「继续编辑」「保存并关闭」「不保存关闭」。没有修改时直接关闭。单独关闭缝合、分支或世界书面板也会检查相应草稿。

保存失败时保留面板和未保存数据；部分内容已经保存成功时只保留剩余待保存项。上下两侧若正在修改同一份预设且草稿不同，则阻止批量保存，避免互相覆盖。搜索、选择、展开等界面状态不计为未保存修改。收藏库和正则的即时保存流程保持原有行为。

这不是自动保存，也不拦截刷新网页、关闭浏览器或卸载扩展。切换预设的原有流程未改变。

## 实现与验证

- `workshop-editing-core.js`：对应关系、只复制开关和分批保存的无 DOM 逻辑。
- `workshop-editing.js`：按需创建并销毁的确认窗口。使用独立样式、实色背景和键盘焦点限制。外层定位隔离主题样式，并跟随所属窗口的可见视口；视口事件只在弹窗打开期间监听，关闭时移除并取消待执行的布局更新，不新增常驻定时器或观察器。
- 批量更新条目数组一次，不生成手动对应的候选列表。缝合草稿使用缓存的深比较，不在每次输入时序列化完整正文。
- `npm run test:workshop-editing`：匹配歧义、字段与顺序保留、大列表、部分保存失败与同目标冲突。
- `npm run test:workshop-editing-browser`：实际 Vue bundle、手机与桌面铅笔旁入口、不同宽度与自定义标题宽度、反转方向、旧对比入口、自动对应及未匹配条目保留、撤销、未保存关闭、保存失败重试、分支与世界书。需要与其他浏览器脚本相同的本地 Playwright 夹具环境。
- `npm run test:workshop-editing-viewport`：320/390/768/1280 宽度、干扰定位的主题样式、TT 安全区、长名称、视口缩小与偏移、横屏回退，以及取消、应用、关闭后的监听清理；支持 Chromium 和 WebKit。

浏览器夹具模拟酒馆数据接口，不代表已经在实体手机或真实 ST/TT 服务端完成验证。
