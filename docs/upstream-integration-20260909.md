## 重叠修改如何融合

1. **标题与快照入口**：沿用作者真实按钮及快照业务。Xiaoci 的顶栏布局移动真实按钮 DOM；快照模块增加从同一 `.pm-header` 找回 `.title-content` 的路径，避免移动后丢失捕获状态标记或保存按钮。录制时由作者管理已暂存的保存按钮，顶栏整理不会将它反复移回；导入／导出等动作仍按录制状态隐藏。作者新增的桌面固定宽度在统一布局下恢复设备适配，保留原生保存按钮、录制事务和主页快照逻辑。
2. **悬浮入口**：在交给统一控制器之前，先执行作者的快照状态、分支显示、分支互斥及批量管理绑定。旧拖动路径在统一控制器存在时停止接管。
3. **通知与独立中控**：保留作者通知处理函数、存储和开关；修正原先依赖“中控位于主面板内”的样式作用域，使中控独立打开后仍能显示这些按钮。
4. **草稿与快照**：Xiaoci 缓存负责重开及重启；作者的 `refreshDisplayedPrompts`、快照回滚和原生运行态同步负责明确的快照操作，保留其原子刷新能力。
5. **新增作者模块的清理**：统一卸载放到所有业务模块安装之后；把快照、原生预设入口和手机开关热区纳入按实例归属清理，同时覆盖顶层和 iframe 存储的服务。旧执行实例不能卸载新实例的服务。
6. **观察器与指针**：作者快照发现阶段改为观察 body 直接子节点；原生预设入口先同步挂载，尚未就绪时仅观察 body 直接子节点及已存在的预设栏，懒加载设置在点击／聚焦时发现。快照面板内仍保留必要的业务监听。手机开关热区及比例手柄按设备在 pointer 和 touch 之间二选一。
7. **冻结主题**：作者新增的无主题工具栏静止态规则仅在未启用 Xiaoci 材质时生效，防止共享 CSS 间接改变验收视觉。

## 本次交互修复

- 条幅默认宽度取当前设备视口的一半，默认高度也取半屏；宽度的旧保存值和手动调节上限均限制在半屏以内。360px 宽视口默认 180px；800px 宽视口默认 400px。窄手机上头部控件可换行。
- 触屏锁按钮提供 44×44px 点击区域，与滑杆保持间隔。锁定前提交待显示的预览；锁定后迟到的 input/change 不能覆盖数值。新一次触摸不会被上一次滚动的防误触时窗吞掉。
- 点击已解锁数值即可输入；输入过程只保留局部文本，确认或失焦时才应用。关闭中控会回收待处理预览，并释放输入法／键盘几何状态。锁定只刷新当前行；中控自身尺寸预览只写中控节点。
- 新增小型 `workshop-window-stack.js`，主界面、中控和条幅按打开顺序分配层级。展开手柄与条幅共用层级，收起悬浮球恢复可触达的入口层级。无需全树监听或额外 pointer handler。
- 多界面拖动继续只写缓存表面的 transform，双界面占比预览只写网格轨道并按帧合并。调整层级避免条幅在其他窗口的模糊层下面移动；比例手柄取消重复事件通道。保留松手终点和取消回滚。
